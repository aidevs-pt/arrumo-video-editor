# Roadmap

Where Arrumo is heading. It's a direction, not a promise: priorities move with what people tell us, and nothing here has a date. Follow each item's progress on the [roadmap board](https://github.com/orgs/aidevs-pt/projects/1), where every item is an issue you can react to or comment on. To suggest something new, open a [discussion](https://github.com/aidevs-pt/arrumo-video-editor/discussions) or a [feature request](https://github.com/aidevs-pt/arrumo-video-editor/issues/new/choose).

## Now: the first release

- **Signed Windows installers**, so Windows installs without security warnings. macOS builds are already signed and notarized. Until then, the release notes explain how to open the Windows installer.
- **Tested on real machines**: installation, onboarding, a full video and updates, on every platform.

## Next

- **Plugins in their own sandbox**, with only the files, network and media access each one declares.
- **More from each provider**: features of ElevenLabs, OpenAI, Gemini and Higgsfield that the official plugins don't use yet.
- **A Blender plugin**, so the agent can build and render 3D scenes, such as product shots, 3D titles and logo reveals, with Blender on your computer.
- **Linux on ARM**: installers for 64-bit ARM computers and boards.
- **Guides for common videos**: step-by-step tutorials for explainers, product launches, social clips and more, made with Arrumo itself.

## Later

- **More agents.** Any agent can join through the [Plugin SDK](https://github.com/aidevs-pt/arrumo-plugin-sdk); we'll help the community add the ones people ask for.
- **App stores**: the Microsoft Store and the Mac App Store, alongside the direct downloads.
- **Community plugins** listed in the registry next to the official ones.
- **Signed Linux packages**: GPG signatures for the AppImage and RPM. Updates are already signed.

## Done recently

- Preview builds for Windows, macOS and Linux with every release, and signed, notarized macOS builds.
- The agent can order music, sound effects, voice-over, images and clips from any step, within limits you set in Settings › Quality.
- Voice-over and sound effects in every format, including portrait versions cut their own way.
- New animations, like lower thirds, designed while the agent edits your footage, reviewed against a grid and a safe-area box.
- The agent sees each whole clip and its sound waveform when cutting, and gets tips for the platform and formats you deliver.
- Planned images, clips, sounds and animations can be previewed and played during generation.
- Model, effort and web search settings for agents apply to runs already in progress.
- Official plugins in the registry, installable and updatable from inside the app with checked releases.
- Arrumo finds your agent even when it isn't on the usual path, or you can choose its program.
- Licenses and open-source credits in Settings › About.
- Messages from the Arrumo team at launch, signed so only we can send them, such as "please update by hand".
- A changelog in every release and in the update dialog.
- FFmpeg included in the installers.

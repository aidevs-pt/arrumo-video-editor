# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

The interface ships in a desktop Tauri window for Linux, Windows, and macOS.

## Stack

Tauri 2, Rust, SQLite, statically exported Next.js, shadcn/ui, and Motion.

## Users

Video creators who review and organize raw footage, brand assets, and recurring production workflows.

## Product Purpose

Organize production around workspaces and reusable profiles. Let creators direct Codex or Claude Code through video production and review the artifacts before final delivery.

## Brand Commitments

Use the supplied Arrumo identity. The application supports English, Spanish, and Portuguese, resizable desktop windows, keyboard controls, and reduced motion.

# Designing animations

- One animation, one idea. Write down what the viewer should understand when it ends, then design only for that.
- Motion should ease: fast out, slow landing for reveals; smooth in and out for continuous moves. Constant-speed motion looks mechanical.
- Reveal elements one after another with a short pause between them, never several at once.
- Hold the final frame for at least a second so it can be read before the cut.
- When text types on, keep its anchor fixed to the full line so it does not slide while it grows.
- Use the brand's colours, at most one or two accents, and generous empty space. Large type beats long sentences.
- Size everything relative to the frame so the same animation works in landscape and portrait.
- An animation that plays over footage must leave the subject visible; an animation between clips can fill the frame.
- Name and describe the animation so it can be found and reused later: what it shows, where it fits, how long it runs.

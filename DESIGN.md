# Desktop workspace design

The start screen uses a warm paper background and dark ink. A compact app bar carries the supplied black-and-white Arrumo icon. The workspace list gets the wider column, while a tinted panel contains the creation form. At narrow desktop widths the form stacks above the list.

Use shadcn controls with visible keyboard focus and translated labels. Workspace additions have a short entrance animation that respects reduced motion. Loading, empty, unavailable, and error states each have explicit text.
